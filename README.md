The Gilded Hour — a top-down museum heist in one room: cross the gallery between guard vision cones and sweeping cameras, empty the glass cases, pick the vault lock, take the Sunstone, and slip out the south door before the alarm meter fills. Three nights, finite smoke bombs and decoy coins, synthesized sound, no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD or arrows move, Shift sneaks, E works with your hands, Q drops smoke, F tosses a decoy coin toward the mouse.
